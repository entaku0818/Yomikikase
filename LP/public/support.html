よくあるご質問

音声が再生されません

端末の音量と、本体側面のサイレントスイッチを確認してください。また、iOS の 設定 → アクセシビリティ → 読み上げコンテンツ → 声 から、お使いの言語の音声データがダウンロードされているかご確認ください。音声データが未取得の言語では読み上げが始まりません。

PDF が 3 件までしか登録できません

無料版では PDF の登録は 3 件までです。プレミアムプランにご登録いただくと、PDF を無制限に登録でき、広告も表示されなくなります。

読み方（発音）が正しくありません

専門用語・固有名詞・ブランド名などは、アプリ内のユーザー辞書に読み方を登録すると正しく読み上げられます。登録した辞書はエクスポートすることもできます。

他のアプリを開くと読み上げが止まります

バックグラウンド再生に対応しています。止まってしまう場合は、iOS の 設定 → 一般 → Appのバックグラウンド更新 が有効か、低電力モードがオンになっていないかをご確認ください。

オフラインでも使えますか？

音声は端末内で生成されるため、オフラインでも読み上げできます。ただし Web ページの取得や Google ドライブからのファイル読み込みには通信が必要です。

Web ページが読み込めません

ログインが必要なページ、有料会員限定のページ、JavaScript で本文を後から描画するページは、本文を取得できないことがあります。その場合は本文をコピーしてテキスト入力からお試しください。

対応している言語は？

10 言語以上の音声エンジンに対応しています。読み上げ速度は 0.5〜2.0 倍速、音声の高さも調整できます。

スキャンした印刷物がうまく読み取れません

明るい場所で、文字が歪まないよう正面から撮影してください。手書き文字や装飾の多いフォントは認識精度が下がることがあります。

機種変更しました。プレミアムを引き継ぐには？

購入時と同じ Apple ID でサインインし、アプリ内の「購入を復元」をお試しください。解約は iOS の 設定 → ユーザー名 → サブスクリプション から行えます。

読み込んだファイルは外部に送信されますか？

いいえ。コンテンツはすべてデバイス内で処理されます。アカウント登録も不要です。

Support (English)

No audio plays

Check the volume and the silent switch. Also open Settings → Accessibility → Spoken Content → Voices and make sure the voice data for your language has been downloaded.

I can only add 3 PDFs

The free plan is limited to 3 PDFs. Premium removes the limit and hides ads.

A word is pronounced incorrectly

Add the term to the in-app user dictionary with your preferred reading. Dictionaries can be exported.

Does it work offline?

Yes — speech is generated on-device. Fetching web pages or Google Drive files still needs a connection.

Restoring Premium on a new device

Sign in with the same Apple ID and use "Restore Purchases" in the app. Manage or cancel via Settings → your name → Subscriptions.
