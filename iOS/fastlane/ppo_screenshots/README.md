# プロダクトページの最適化（A/B テスト）用スクリーンショット

App Store Connect の「プロダクトページの最適化」で使う差し替え案。
`fastlane/screenshots/`（公開用）とは分けて置いているので、`deliver` ではアップロードされない。
アップロードとテスト作成は ASC の画面から手動で行う。

目的: 検索結果からプロダクトページを開く率（2026-10 時点 5.0%）を上げる。

## ja / iPhone 6.7インチ（1320x2868）

並べ替えだけを比べるため、画像は公開中の `fastlane/screenshots/ja/` と同じファイル（md5 一致）を使い、順番だけを変えている。

| | 1枚目 | 2枚目 | 3枚目 |
|---|---|---|---|
| 現行（対照） | 家事も通勤も、ながら聴き。 | PDFも本もWebも、すぐ声に。 | 人気のキャラ音声で読み上げ |
| 案B `ja/planB/` | PDFも本もWebも、すぐ声に。 | 人気のキャラ音声で読み上げ | 家事も通勤も、ながら聴き。 |
| 案C `ja/planC/` | 人気のキャラ音声で読み上げ | PDFも本もWebも、すぐ声に。 | 家事も通勤も、ながら聴き。 |

キャラ音声の小見出し「VOICEVOX：ずんだもん・四国めたん ほか」はクレジットとして残している。
キャラ名はサブタイトル・キーワードには入れない。

## 作り直すとき

`VARIANTS="B C" iOS/scripts/appstore_screenshots.sh ja` で `build/appstore_screenshots/final/ja_B/`・`ja_C/` に同じ並びで出る
（並びは `scripts/compose_screenshots.py` の `VARIANTS`）。
ただし作り直すと実画面が今のアプリになるため、公開中の画像（対照）と画面の中身が変わる。
並べ替えだけの比較にしたいときは、公開用と同じ回で撮った画像を使うこと。
