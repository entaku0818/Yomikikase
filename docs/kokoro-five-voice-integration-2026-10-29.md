# 5音声のアプリ対応と会話音声の比較（2026-10-29）

目的は、凛・狐・雪・芽・雲で任意の日本語を読み上げられるようにし、会話・感情のある声を低コストで比較すること。サンプル音声の同梱ではなく、入力文章から端末内で生成する。ストアへの配布やクラウド音声の本番接続は行っていない。

## Android

- `kokoro/` のモデル取得・ONNX生成・音声選択を main ソースに追加。従来の debug 専用 G2P / 音素分割ヘルパーを main に移した。
- 日本語の声選択から5声を選べる。選択と試聴を分離し、声の保存、任意文章の再生、一時停止・再開・停止、端末音声への切り替えに接続。
- 初回モデルは 92,361,116 bytes。公開モデルのリビジョンと SHA-256 を固定し、完全に取得・検証できたものだけ利用する。モデルはバックアップ対象外、生成音声は削除可能なキャッシュに保存する。
- 音声埋め込み5個（各522,240 bytes）、トークナイザー、ライセンスを assets に同梱。モデル取得後の生成にAPI通信・料金は不要。
- 推論はバックグラウンドで直列化。停止は次のネイティブ推論境界で反映する。通信キャンセルはブロッキング読み込みの終了またはタイムアウトまで待つことがある。
- 短い文を最大120文字のまとまりにまとめ、文ごとの生成による途切れを減らす。元の文章の範囲を保持し、ハイライト・再開位置に使う。
- 再生直後の停止で foreground service の起動前に stopService が呼ばれるクラッシュを修正。停止インテントを起動の後に処理する。記号だけの入力、生成中の端末音声切り替えでも再生・通知を終了する。
- モデル取得の失敗・破損は再試行を表示し、生成に失敗した場合は別の声へ無言で切り替えない。

モデル: [onnx-community/Kokoro-82M-v1.0-ONNX](https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX)

- revision: `1939ad2a8e416c0acfeecc08a694d14ef25f2231`
- model SHA-256: `fbae9257e1e05ffc727e951ef9b9c98418e6d79f1c9b6b13bd59f5c9028a1478`
- 5声: `jf_alpha`, `jf_gongitsune`, `jf_tebukuro`, `jf_nezumi`, `jm_kumo`

## iOS

既存のMLXによる5音声の生成経路を使用する。

- 音声選択時のエンジン有効化と、言語に合わない保存済み音声の補正を追加。日本語・英語以外は端末音声へルーティングする。
- 試聴のキャンセル・失敗・終了状態を管理し、連打や画面を閉じたときに古い音声が後から再生されないようにした。
- 生成時に速度を適用したKokoro音声には再生時に同じ速度を重ねない。PDFもAVSpeechの速度をKokoroの速度へ変換してから生成する。
- CFStringTokenizerの読みを補正。単独の「は」が文字に続く場合や挨拶の一部を「わ」と読む。品詞解析ではなく限定的な推定なので、全ての助詞・固有名詞・文脈を解決するものではない。

## 検証

- iOS Simulator: `KokoroVoiceIntegrationTests`、`KokoroEngineTests`、`KokoroTTSClientTests`、`SettingsReducerTests`、`JapaneseG2PProcessorTests` の103テスト成功。
- Android: Debugビルド、180単体テスト、Lint成功。Lintは既存警告が残っている。
- Android API 33エミュレーター: 実モデルで5声の異なるWAVを生成し、生成キャンセル後の復帰を確認。Composeの音声選択と本番ViewModelを経由した任意文章の再生・一時停止・再開・停止を検証。
- 実モデルのinstrumentationテストは `-e kokoroModelTest true` を指定する。既定のCIではモデル通信を発生させない。上記モデルをアプリの `no_backup/kokoro-v1/model.onnx` に用意する必要がある。
- SwiftLintは変更対象でエラーなし。既存ファイルの警告は残る。
- iPhone / Android実機での聴感・発熱・バッテリー評価は未実施。iOS Simulatorのテストは実機MLX推論の音質保証ではない。

## 会話らしさの比較と残る制約

既存のKokoro 5声の会話文サンプルと、同じ95文字を使ったChirp 3 HD（Aoede / Charon）・WaveNet Bの3サンプルを比較用に作成した。音量を約 -22 LUFS に統一し、ピッチ・速度の後加工や感情プロンプトは使っていない。Kokoro比較サンプルはPython生成で、アプリ端末の録音ではない。会話の自然さは試聴で判断する。

今回の3 API呼び出しは合計285文字。無料枠適用前の単価計算では $0.00608（請求実績ではない）。クラウド接続はアプリには追加していない。

[Google公式料金](https://cloud.google.com/text-to-speech/pricing)（2026-10-29確認）: Chirp 3 HD は月100万文字無料・超過後 $30 / 100万文字、WaveNet は月400万文字無料・超過後 $4 / 100万文字。無料枠は各アプリ利用者ごとではなく、課金対象の利用量に対して適用される。

現在の5音声には感情を指示する機能はない。Androidの数字や固有名詞の読み、iOSの文脈依存の読みには限界がある。感情を強く表現する音声を採用する場合は、まず同じ文で比較し、使用するエンジンと運用費を決める。
