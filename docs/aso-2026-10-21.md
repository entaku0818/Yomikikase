# 日英App Storeメタデータ改善

対象: `iOS/fastlane/metadata/ja` と `en-US`。ローカルの掲載文を更新。App Store Connectへのアップロード・審査提出は未実施。

## 狙いと変更

- 日本語タイトルは既存の「読み上げアプリ ナレーター：PDF・本・Webを音声化」を維持。サブタイトルは「人気キャラの声でもPDF・本を朗読」から「電子書籍の朗読・聴く読書・ながら学習に」に変更し、用途を補足する。
- 英語タイトルを `Voice Narrator: Text to Speech`、サブタイトルを `Read Aloud: PDF, EPUB & Web` に変更。機能を自然な英語で伝える。
- キーワード欄はタイトル・サブタイトルとの重複を減らし、日本語ではオフライン・バックグラウンド・リスニング、英語では study・notes・articles・pronunciation などの用途を補完する。
- 説明文とプロモーション文の冒頭を「通勤や家事の合間に資料や本を聴く」という利用場面に統一する。
- 「何でも」「コピペも変換も不要」などの過大な表現を削除。標準音声のオフライン再生とキャラクター音声の通信要件を区別する。
- Googleドライブは「ファイル」アプリ経由であること、ハイライトは音声によって利用可否が異なること、無料体験は購入画面のオファーと適用条件に従うことを明記する。

検索ボリューム・順位・獲得実績のデータは取得していない。選定語は機能と利用場面から立てた仮説であり、順位やダウンロード増加を保証するものではない。

## 機能表現の確認先

- `iOS/VoiceYourText/Dependencies/TextFileImportClient.swift`: Googleドライブの取り込み方式
- `iOS/VoiceYourText/Dependencies/WebPageFetchClient.swift`: HTTPSページからのテキスト抽出
- `iOS/VoiceYourText/TextInputView.swift`: 音声エンジンの選択・ハイライト・文字数制限
- `iOS/VoiceYourText/Features/Settings/SubscriptionPlanInfo.swift`: 無料体験期間とユーザー適格性

## 検証

日英の name / subtitle / keywords / promotional_text / description の文字数を確認。上限はそれぞれ 30 / 30 / 100 / 170 / 4,000。
キーワードの空項目・カンマ後の余分な空白・欄内の同一語重複も確認する。今回の変更は掲載テキストのみで、アプリのビルドは不要。

## 公開後の比較

1. 反映日と対象バージョンを記録する。
2. App Store Connectで、公開前後それぞれ28日間の日米ストアの App Store Search 経由のインプレッション、プロダクトページ閲覧、初回ダウンロード、コンバージョン率を同じ条件で比較する。
3. 広告出稿・価格変更・アプリ更新など同時期の施策を記録し、単純な増減をASOだけの効果と断定しない。
4. 次の施策ではスクリーンショット先頭3枚を「PDF・本を聴く」「速度を調整」「文章を目で追う」の順で検証する。今回は画像を変更していない。
